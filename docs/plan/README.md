# Historical Planning Material

Everything in this directory is historical planning evidence. It supplies
context, not current architecture, lifecycle, phase-route, or implementation
authority.

The directory contains two kinds of material:

1. older phase-planning documents, which record earlier design work and project
   history but are not the current Phase 63–90 roadmap;
2. dated product/roadmap snapshots, including
   [`pietto_product_plan_2026-09-02.md`](pietto_product_plan_2026-09-02.md),
   which preserve the view at their stated date.

Neither category authorizes implementation. Current readers should use:

- [`docs/architecture/`](../architecture/) for durable cross-phase product and
  architecture laws;
- the [roadmap](../roadmap.md) for current phase-level ownership and release
  milestones;
- current published [phase/slice contracts](../spec/) for exact routes and
  phase-specific authority;
- [status](../status.md) for the lifecycle summary; and
- live Git plus natural exact-head CI for publication and lifecycle authority.

[`AGENTS.md`](../../AGENTS.md) remains the live repository working authority.
