# Phase 58 Slice 16 Pure Differential Compatibility Assurance v1

## Scope

Slice 16 proves that the same already-published authored Project Explain inputs
produce the same contractually invariant observations across supported Python
versions, fixed hash seeds, project and source relocation, source-tree imports,
and an isolated installed wheel. It adds no production semantics, public field,
runtime authority, CLI route, package input, profile, catalog, or status.

The bounded corpus reuses Slice 15 semantics rather than creating another
semantic campaign:

```text
matrix      multi-package, multi-target, selected/no-match, conflict, gaps
empty       explicit empty targets and INDETERMINATE
portable    non-empty targets with zero requirements
diagnostic  schema-v2 extension requirement with a real target
resource    missing explicit project root
single_file legacy Semantic Metadata Artifact v1 CLI checkpoint
```

All project scenarios begin from real `pietto.toml`, package manifests,
dependency declarations, package source bytes, profiles, targets, requirements,
and typed selector sidecars. The probe never constructs a final matrix,
inspection, Project Explain payload, envelope, or catalog selection result.

## Canonical Observation

`tests/_pietto_project_explain_differential_probe.py` is a test asset, not a
public artifact. It records only:

```text
runtime outcome
explicit envelope/payload JSON value
exact public JSON document
exact public text document
JSON/text CLI exit status
legacy single-file JSON/text documents and exits
package version
```

The committed common expectation in the Slice 16 test is a named per-scenario,
per-surface SHA-256 manifest. Each digest is paired with its exact scenario and
surface; the test also retains and asserts the complete actual structured and
byte observations, so mismatches are not opaque. Python 3.12 and 3.13 consume
the same manifest. There is no version-specific or seed-specific expectation.

The comparator does not sort lists or keys, deduplicate occurrences, strip
whitespace, remove diagnostics, replace paths, canonicalize statuses, or
re-serialize public JSON. It compares complete observations directly across
executions and exact serializer/text bytes against the common references.

## Hash Seed And Ambient Matrix

The exact reproducible seed set is:

```text
PYTHONHASHSEED = 0, 1, 7, 4294967295
```

Every seed runs the same complete corpus in a separate process and project
root. Package, requirement, target, catalog, diagnostic, and artifact-reference
order are compared without sorting. The probe also runs from distinct cwd
values with a different irrelevant `PIETTO_SLICE16_IRRELEVANT` value; that
variable is not a Pietto authority and cannot affect observations.

## Python Version Assurance

Trusted local Python 3.12 and 3.13 interpreters run the same probe when
available. Natural CI runs the complete committed test under its exact 3.12 and
3.13 matrix. Both versions must match the same `EXPECTED_SURFACE_SHA256`
manifest, so two green jobs prove parity against one comparison authority
rather than unrelated success.

No interpreter is downloaded by the focused harness. A supported interpreter
not already present locally is deferred to its natural CI matrix job.

## Relocation And Ambient Authority

Equivalent authored projects are constructed under distinct temporary roots
and compared exactly. A source-relocation branch copies only `src/` plus the
two required test-side probe/scenario files, runs outside the original
repository cwd, and compares the complete observation. Caches, Git state,
untracked files, home identity, and the original cwd are not copied as
authority.

Project Explain logical paths and detached locations are already relocation
stable. The test performs no output normalization to obtain equality.

## Installed Wheel Differential

The focused harness builds one wheel from the exact candidate working tree
with offline project tooling, then installs only that local Pietto wheel with
`--offline --no-deps --target` into a temporary wheel target while the uv cache
starts empty. Dependency resolution is deliberately disabled: the trusted
pytest interpreter supplies the already-installed locked third-party
dependencies, while the wheel target is first on `PYTHONPATH`. The probe runs
from a neutral temporary cwd outside the repository and verifies
`pietto.__file__` resolves under the wheel target rather than the source
repository or its editable installation.

This separation makes the focused source/wheel comparison independent of
network and cache warming without weakening Pietto import provenance. The
central package smoke separately retains complete dependency resolution,
isolated-environment installation, and package inventory ownership.

Installed runtime, JSON, text, exits, order, single-file explain, and version
must equal the source-tree observation. This behavioral comparison complements,
but does not replace, the central package smoke and its complete wheel/module
inventory.
